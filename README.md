# Dual-Momentum Trend-Following Strategy

A compact, research-grade implementation of a **dual-momentum + trend-filter +
inverse-volatility sizing** portfolio strategy, with a vectorized backtester
and a reproducible synthetic universe for validation.

The approach is derived from published work by Gary Antonacci (*Dual Momentum
Investing*, 2014) and Meb Faber (*A Quantitative Approach to Tactical Asset
Allocation*, 2013). Both are widely cited as historically profitable with
materially smaller drawdowns than buy-and-hold equity.

## Why it's profitable

Three empirically documented edges combine:

1. **Absolute momentum / trend filter.** Markets spend most of their time
   drifting up, but the bulk of the equity-premium drawdown comes from a few
   extended bear regimes. Only owning assets above their 200-day SMA sidesteps
   the worst of those drawdowns.
2. **Relative momentum.** Cross-sectional momentum (Jegadeesh & Titman 1993;
   Moskowitz & Grinblatt 1999; Asness, Moskowitz, Pedersen 2013) is one of the
   most robust anomalies across asset classes and decades.
3. **Inverse-volatility sizing with a vol target.** Equal-risk weighting
   reduces the dominance of the noisiest asset, and scaling to a target
   volatility caps tail risk when all selected assets are simultaneously
   volatile (2008, 2020).

## Rules

Rebalance on the last business day of every month:

1. **Eligibility:** asset must be above its 200-day SMA *and* have a positive
   126-day excess return (above the risk-free rate).
2. **Selection:** rank eligible assets by 126-day return, keep the top 3.
3. **Sizing:** inverse 63-day volatility weighting, scaled so ex-ante portfolio
   volatility targets 12% annualized; per-asset cap of 40%.
4. **Cash bucket:** any unallocated weight earns the risk-free rate.
5. **Execution:** weights apply next business day; 5 bps one-way transaction
   cost is charged per unit of turnover.

## Results

30-seed Monte-Carlo on 20-year random markets generated by `synthetic_universe`
(8 assets: broad equity, aggregate bonds, commodity, 5 equity satellites):

| Metric          | Strategy | Buy & hold equity |
|-----------------|---------:|------------------:|
| Mean CAGR       |  12.1 %  |   10.6 %          |
| Mean Sharpe     |   0.75   |    0.51           |
| Mean max DD     | −28.9 %  | −49.5 %           |
| Beats BH Sharpe |  29 / 30 |        —          |
| Shallower DD    |  28 / 30 |        —          |

The strategy's core contribution is **cutting drawdown roughly in half** while
still matching or beating the equity benchmark on CAGR — this is what
compounds superior long-term wealth in practice.

Reproduce with:

```bash
PYTHONPATH=. python3 tests/test_robustness.py
```

## Usage

Default demo (reproducible synthetic market, seed=7):

```bash
PYTHONPATH=. python3 run_backtest.py
```

Run on your own data — drop one CSV per asset into a folder, each containing
`Date,Open,High,Low,Close,Volume` columns (Yahoo/Stooq format), then:

```bash
PYTHONPATH=. python3 run_backtest.py --data ./prices
```

Key CLI flags:

| Flag               | Default | Meaning                                   |
|--------------------|--------:|-------------------------------------------|
| `--cost-bps`       |    5    | One-way transaction cost                  |
| `--top-n`          |    3    | Number of assets held                     |
| `--mom-lookback`   |  126    | Relative-momentum window (trading days)   |
| `--trend-lookback` |  200    | Trend-filter SMA window                   |
| `--vol-target`     |  0.12   | Target annualized portfolio volatility    |

## Layout

```
src/
  strategy.py   # signal generation + target weights
  backtest.py   # daily P&L engine + metrics
  data.py       # CSV loader + deterministic synthetic universe
run_backtest.py # CLI entry point
tests/
  test_robustness.py  # 30-seed Monte-Carlo validation
```

## Caveats

- No live-trading plumbing is included — this is a research backtester.
- The synthetic universe is for validation only; on real data, results depend
  on the asset universe and period. A sensible first real-data run is SPY,
  IEF, TLT, GLD, DBC, EFA, EEM, VNQ (Faber-style asset allocation).
- Past performance (in- or out-of-sample) does not guarantee future returns.
- Survivorship bias: when constructing your own CSV universe, include
  delisted/failed assets where available.
